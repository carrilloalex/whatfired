Privacy Policy

WhatFired helps you inspect analytics events while keeping the inspected data inside your browser.

Effective November 23, 2026

No external servers WhatFired does not send captured data to the developer.
Local processing Analytics activity is processed and displayed on your device.

1. Scope

This Privacy Policy explains how the WhatFired browser extension ("WhatFired", "the extension", "we" or "us") handles information when you use it. WhatFired's single purpose is to let users inspect and understand analytics events triggered by their interactions on a website.

2. Information processed by the extension

When you activate WhatFired on a website, the extension may process the following information as needed to provide its user-facing inspection features:

  • Web browsing information: the active page URL, hostname, path, page title, navigation destination, and timestamps associated with inspected activity.
  • User activity: clicks, form submissions, navigation actions, and descriptive labels or selectors for the interface element involved.
  • Website and analytics content: analytics provider names, event names and types, event properties, values, and analytics request payloads.
  • Identifiers included in analytics events: user, anonymous, group, session, or message identifiers when the website itself includes them in an analytics event.

Because analytics implementations are controlled by the websites you inspect, their event payloads may contain personal information. WhatFired displays this information locally for the inspection task. It does not transmit it to us.

3. Information WhatFired is not designed to collect

WhatFired does not intentionally collect passwords, authentication credentials, cookies, payment-card details, private keys or the text you enter into form fields. The extension redacts values whose property names indicate common sensitive data such as passwords, authorization tokens, cookies, secrets, credit-card data and API keys.

Important: redaction is a safety measure, not a guarantee that every website uses predictable property names. Only activate the extension on websites and environments where you are authorized to inspect analytics data.

4. How information is used

Processed information is used only to provide WhatFired's single purpose: showing the relationship between a user interaction and the analytics events it triggered, letting the user search and filter those events and allowing event names and properties to be copied into analytics tools.

5. Local storage and retention

  • Recent captured activity is stored in chrome.storage.session so the popup can display it and so recent events are not lost if Chrome suspends the extension's background worker.
  • Chrome clears session captures when the browser restarts or when the extension is reloaded, disabled, or updated.
  • WhatFired may store a source-filter preference in chrome.storage.local for up to 90 days. This preference contains only a website origin and the selected analytics provider name. It does not contain page paths, captured events, properties or payloads.
  • You can clear captured activity from the extension interface and revoke optional website access through your browser's extension controls at any time.

6. Data transmission and sharing

WhatFired has no developer-operated server and makes no external network requests of its own. Captured analytics data is not transmitted to us, sold, rented, shared or transferred to third parties. The extension does not use captured data for advertising, profiling, credit decisions, lending or any purpose unrelated to its analytics-inspection functionality.

7. Permissions

  • activeTab: provides temporary access only after you open WhatFired on the current tab.
  • scripting: injects the extension's bundled static observer so it can identify analytics activity in the page context. WhatFired does not download or execute remote code.
  • storage: stores recent captures in session storage and remembers the optional provider-filter preference described above.
  • Optional website access: if you explicitly choose to always track a website, WhatFired can continue working on that site across reloads and new tabs. Access is requested one website at a time and can be revoked through your browser's extension controls at any time.

8. Security

WhatFired limits website access, keeps extension storage unavailable to page scripts, validates messages passed from inspected pages, treats captured values as untrusted display data and does not include permissions for browsing history, cookies, downloads, native messaging, debugger access, proxy configuration or the local file system.

9. Limited use

WhatFired's use of information is limited to the extension's prominently disclosed user-facing analytics-inspection purpose. We do not use or transfer information for unrelated purposes and we do not use or transfer information to determine creditworthiness or for lending.

WhatFired's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

10. Children's privacy

WhatFired is a browser tool and is not directed to children. We do not knowingly operate any service that receives personal information from children through the extension.

11. Changes to this policy

We may update this policy if WhatFired's functionality or data-handling practices change. The effective date at the top of this page will be updated when changes are made. Material changes will be reflected in the extension's disclosures before the changed version is published.
